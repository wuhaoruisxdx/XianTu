## 🎯 项目概述

### 核心理念

将《仙途》从修仙主题转换为现代财富积累主题的文字冒险游戏，保留原有的游戏机制、页面风格和AI驱动的动态叙事系统，实现"修仙"到"赚钱"的完整主题转换。

### 目标定位

**从修真求道者 → 到财富追求者**

一个以现代商业世界为背景的AI驱动文字冒险游戏，玩家从社会底层起步，通过学习技能、建立人脉、投资理财、创业经营等方式，逐步积累财富，提升社会地位，最终成为商业巨擘。

### 游戏特色

- 🤖 **AI动态叙事** - 生成真实的商业场景和人际互动
- 💼 **完整财富体系** - 从打工到创业，从小本生意到跨国集团
- 📊 **智能判定系统** - 基于技能、资产、人脉等多维度计算成功率
- 💰 **多元赚钱方式** - 投资、创业、副业、炒股、房产等
- 🌐 **开放世界** - 探索现代都市，触发商业机遇
- 📱 **全平台适配** - 保持原有的响应式设计

### 2. 核心玩法循环

#### 每日行动系统

每天玩家可以进行多个行动，直到时间或精力耗尽：

**主要行动**（消耗较多时间和精力）
1. **工作赚钱**
   - 上班打工：每天8小时，稳定收入，按日/周/月结算
   - 做项目/接单：灵活时间，收入波动，项目完成后结算
   - 创业经营：全天投入，高风险高回报，长期收益

2. **技能学习**
   - 线上课程：1-7天不等，低成本，自学能力要求高
   - 培训班：数周到数月，高成本，系统性强
   - 实战练习：边做边学，时间灵活，效果最好

3. **商业投资**
   - 股票投资：下单即时，每天关注市场变化
   - 房产投资：看房、谈判数天，交易完成后长期持有
   - 创业投资：尽职调查数周，投资后定期关注

**次要行动**（消耗较少时间）
1. **社交活动**
   - 参加聚会/会议：半天到1天，建立人脉
   - 拜访重要人物：数小时，深化关系
   - 维护老关系：电话/聊天，保持联系

2. **健康管理**
   - 锻炼身体：1-2小时，恢复健康，提升体质
   - 休息放松：半天到1天，恢复精力
   - 体检/治疗：半天到数天，应对健康问题

3. **信息收集**
   - 行业调研：数小时到数天，发现商机
   - 学习新闻：每天1小时，把握趋势
   - 人脉打听：数小时，获取内幕消息

#### 时间流逝机制

**工作日模式**（周一至周五）
- 固定工作：8小时
- 剩余时间：可用于学习、社交、副业
- 精力消耗：工作后精力降低，影响其他行动效率

**周末模式**（周六日）
- 全天自由：可专注学习、创业或休息
- 社交活动：更多聚会和人脉机会
- 兼职副业：额外收入来源

**特殊事件**
- AI随机生成：突发商机、行业变动、人际事件
- 玩家选择：是否参与，如何应对
- 时间影响：可能打乱原定计划

#### 收入与支出系统

**收入来源**
- 工资收入：日薪/周薪/月薪，稳定
- 副业收入：灵活，可扩展
- 投资收益：被动，波动大，按日/周/月/年结算
- 一次性收入：项目完成、奖金、继承等

**固定支出**
- 房租/房贷：按月支付
- 生活费：日常吃穿用度，每天消耗
- 社保/保险：按月或按年支付
- 交通通讯：日常消费

**可选支出**
- 学习进修：课程费用，一次性或分期
- 社交消费：聚会、请客，不定期
- 健康投资：健身、保养，按次或按月
- 奢侈消费：提升生活品质，不定期

**现金流管理**
- 每日结算：统计当天收支
- 每周总结：查看本周财务状况
- 每月报表：分析月度收支，调整策略
- 年度汇总：查看年度成长曲线

### 3. 判定系统

#### 成功率计算公式

```
成功率 = 基础概率 × 能力修正 × 技能修正 × 装备修正 × 人脉修正 × 运气因子
```

**示例：投资股票**
- 基础概率：50%（市场平均）
- 能力修正：智商/10 × 情商/10
- 技能修正：投资技能等级 × 0.1
- 装备修正：专业设备加成
- 人脉修正：内幕消息加成
- 运气因子：0.8-1.2随机

**示例：谈判签单**
- 基础概率：30%（行业难度）
- 能力修正：情商/10 × 魅力/10
- 技能修正：销售技能等级 × 0.15
- 装备修正：着装、礼品等
- 人脉修正：介绍人信任度加成
- 运气因子：0.8-1.2随机

## 🔍 潜在挑战与解决方案

### 挑战1：游戏平衡性

**问题**：现代赚钱可能出现"一夜暴富"或"永远打工"的极端情况

**解决方案**：
1. 设置合理的收入/支出比例
2. 投资收益有上限和风险
3. 创业成功率与技能/人脉挂钩
4. 引入税收、通货膨胀等真实因素

### 挑战2：内容重复性

**问题**：打工、投资等行为可能过于重复

**解决方案**：
1. AI生成多样化的工作场景
2. 随机事件打破常规
3. NPC关系带来变数
4. 阶段性目标引导玩家

### 挑战3：主题敏感性

**问题**：金钱主题可能引起价值观争议

**解决方案**：
1. 强调合法赚钱途径
2. 体现风险与回报的平衡
3. 加入社会责任元素
4. 提供多元化成功路径

### 挑战4：AI生成质量

**问题**：AI可能生成不合理的商业场景

**解决方案**：
1. 详细的提示词工程
2. 业务规则约束
3. 数据范围限制
4. 人工测试和调优

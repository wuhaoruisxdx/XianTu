## 前置要求

### 必须安装

- **Node.js**: >= 18.0.0（推荐 18.x 或 20.x）
  ```bash
  node -v  # 检查版本
  ```

- **npm**: >= 9.0.0（随 Node.js 自动安装）
  ```bash
  npm -v
  ```

### 可选安装（如需后端服务）

- **uv**: Python包管理工具（推荐）
  ```bash
  # Windows (PowerShell)
  powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

  # 或使用 pip 安装
  pip install uv

  # 验证安装
  uv --version
  ```

- **Python**: >= 3.10（uv 会自动管理）

## 方式一：仅前端部署（推荐新手）

**适用场景**：
- 只想体验游戏，不需要账号系统
- 使用本地存档（IndexedDB）
- 使用自定义 AI API（Gemini/Claude/OpenAI/DeepSeek）或 SillyTavern 模式

### 1. 克隆项目

```bash
# 如果还没有克隆
git clone https://github.com/qianye60/XianTu.git
cd XianTu
```

### 2. 安装前端依赖

```bash
npm install
```

**可能遇到的问题**：
- 如果安装速度慢，可以使用国内镜像：
  ```bash
  npm config set registry https://registry.npmmirror.com
  npm install
  ```

### 3. 启动开发服务器

```bash
npm run serve
```

### 4. 访问应用

浏览器访问：`http://localhost:8080`

**首次使用**：
1. 选择"单机模式"（不需要后端）
2. 在设置中配置 AI API（或使用 SillyTavern）
3. 创建角色，开始游戏！

## 方式二：前后端完整部署

**适用场景**：
- 需要账号系统
- 需要云存档同步
- 需要创意工坊功能
- 多设备共享存档

### 步骤 1: 前端部署

同"方式一"的步骤 1-3。

### 步骤 2: 后端部署（使用 uv）

#### 2.1 创建虚拟环境并安装依赖

```bash
# 进入项目根目录
cd D:\project\opensource\XianTu

# 使用 uv 创建虚拟环境并安装依赖
uv venv
uv pip install -r server/requirements.txt
```

**说明**：
- `uv venv` 会在项目根目录创建 `.venv` 虚拟环境
- `uv pip install` 会自动下载并安装所有依赖

#### 2.2 激活虚拟环境

**Windows (PowerShell)**:
```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows (CMD)**:
```cmd
.venv\Scripts\activate.bat
```

**Linux/Mac**:
```bash
source .venv/bin/activate
```

**验证激活成功**：
```bash
# 命令行提示符前应该有 (.venv) 标识
python --version  # 应该显示虚拟环境中的 Python 版本
```

#### 2.3 配置环境变量

```bash
# 复制环境变量模板
cp server/.env.example server/.env

# 编辑配置文件（使用你喜欢的编辑器）
notepad server/.env  # Windows
# 或
code server/.env     # VSCode
```

**最小配置** (server/.env):
```env
# 开发环境
ENVIRONMENT=development

# JWT 密钥（生产环境务必修改！）
SECRET_KEY=dev-secret-change-me

# 数据库（SQLite，开箱即用）
DDCT_DB_URL=sqlite://db.sqlite3
```

**生产环境配置**:
```env
ENVIRONMENT=production

# 生成随机密钥（推荐）
SECRET_KEY=你的随机密钥  # 使用 openssl rand -hex 32 生成

# MySQL 数据库（可选）
# DDCT_DB_URL=mysql://user:password@127.0.0.1:3306/xiantu?charset=utf8mb4
```

#### 2.4 初始化数据库

```bash
# 确保在虚拟环境中
cd server

# 初始化 Aerich（数据库迁移工具）
aerich init -t database.TORTOISE_ORM

# 初始化数据库结构
aerich init-db

# 返回项目根目录
cd ..
```

**说明**：
- 使用 SQLite 时会自动创建 `server/db.sqlite3` 文件
- 使用 MySQL 时需要先手动创建数据库

#### 2.5 启动后端服务

```bash
# 方式 1: 使用 uvicorn（推荐开发）
uvicorn server.main:app --reload --port 12345

# 方式 2: 使用 Python 模块运行
python -m uvicorn server.main:app --reload --port 12345

# 方式 3: 生产环境（多进程）
uvicorn server.main:app --host 0.0.0.0 --port 12345 --workers 4
```

**验证后端启动成功**：
- 访问 `http://localhost:12345/docs` 查看 API 文档
- 应该能看到 FastAPI 自动生成的 Swagger UI

### 步骤 3: 配置前端连接后端

修改前端配置以连接本地后端：

1. 启动前端后，进入游戏
2. 选择"联机模式"
3. 在登录页面注册账号
4. 登录后即可使用云存档功能

**前端 API 配置**（如需修改后端地址）：

查看并修改 `src/services/backendConfig.ts`:
```typescript
const API_BASE_URL = 'http://localhost:12345/api';
```

### 步骤 4: 启动完整系统

**使用两个终端**：

**终端 1 - 前端**:
```bash
cd D:\project\opensource\XianTu
npm run serve
```

**终端 2 - 后端**:
```bash
cd D:\project\opensource\XianTu
.\.venv\Scripts\Activate.ps1  # 激活虚拟环境
uvicorn server.main:app --reload --port 12345
```

**访问应用**：
- 前端：`http://localhost:8080`
- 后端 API 文档：`http://localhost:12345/docs`

## 配置说明

### AI API 配置

#### 选项 1: SillyTavern 模式（推荐）

1. 确保 SillyTavern 已安装并运行
2. 在 SillyTavern 中加载仙途扩展
3. 在仙途设置中选择"酒馆模式"

#### 选项 2: 自定义 API 模式

**Gemini API**:
```
模型: gemini-2.0-flash-exp
API Key: 你的 Gemini API Key
API URL: https://generativelanguage.googleapis.com/v1beta/
```

**Claude API**:
```
模型: claude-sonnet-4
API Key: 你的 Claude API Key
API URL: https://api.anthropic.com/v1/
```

**OpenAI API**:
```
模型: gpt-4o
API Key: 你的 OpenAI API Key
API URL: https://api.openai.com/v1/
```

**DeepSeek API**:
```
模型: deepseek-chat
API Key: 你的 DeepSeek API Key
API URL: https://api.deepseek.com/v1/
```

### 数据库配置

#### SQLite（默认）

**优点**：
- 开箱即用，无需安装
- 适合个人/小团队使用
- 自动创建 `server/db.sqlite3` 文件

**配置**：
```env
DDCT_DB_URL=sqlite://db.sqlite3
```

#### MySQL（可选）

**优点**：
- 高性能，适合高并发
- 支持复杂查询和事务
- 适合生产环境

**配置步骤**：
```bash
# 1. 安装 MySQL（略）

# 2. 创建数据库
mysql -u root -p
CREATE DATABASE xiantu CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'xiantu'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON xiantu.* TO 'xiantu'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 3. 配置环境变量
# server/.env
DDCT_DB_URL=mysql://xiantu:your_password@127.0.0.1:3306/xiantu?charset=utf8mb4

# 4. 初始化数据库
cd server
aerich init-db
```

## 生产构建与部署

### 构建前端

```bash
npm run build
```

构建产物位于 `dist/` 目录，可以部署到任何静态服务器（Nginx/Apache/CDN）。

### 生产环境启动后端

```bash
# 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 启动（多进程）
uvicorn server.main:app --host 0.0.0.0 --port 12345 --workers 4

# 或使用 Gunicorn（Linux）
gunicorn server.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:12345
```

### Docker 部署（一键部署）

```bash
# 构建镜像
docker build -t xiantu:latest .

# 运行容器
docker run -d -p 8080:80 -p 12345:12345 xiantu:latest

# 或使用 Docker Compose
docker-compose up -d
```

## 常见问题

### Q1: `npm install` 速度很慢或失败

**解决方案**：
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install

# 或使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

### Q2: `uv` 安装失败

**解决方案**：
```bash
# 方式 1: 使用 pip 安装
pip install uv

# 方式 2: 直接使用 pip + venv
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r server/requirements.txt
```

### Q3: 后端启动报错 "No module named 'server'"

**解决方案**：
```bash
# 确保在项目根目录运行
cd D:\project\opensource\XianTu

# 使用正确的命令
uvicorn server.main:app --reload --port 12345
```

### Q4: 前端无法连接后端

**检查清单**：
1. 后端是否启动成功？访问 `http://localhost:12345/docs` 确认
2. 端口是否被占用？修改端口号
3. 防火墙是否拦截？临时关闭防火墙测试
4. CORS 配置是否正确？查看浏览器控制台错误

### Q5: 数据库迁移失败

**解决方案**：
```bash
# 删除旧的迁移文件
rm -rf server/migrations
rm server/db.sqlite3

# 重新初始化
cd server
aerich init -t database.TORTOISE_ORM
aerich init-db
```

### Q6: 权限错误（Windows PowerShell）

**解决方案**：
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后重新激活虚拟环境
.\.venv\Scripts\Activate.ps1
```

### Q7: AI API 调用失败

**检查清单**：
1. API Key 是否正确？
2. API URL 是否正确？
3. 网络是否畅通？（国内访问 OpenAI 需要代理）
4. API 额度是否用尽？
5. 查看浏览器控制台和网络请求详情

### Q8: 存档丢失或无法加载

**解决方案**：
```bash
# 检查 IndexedDB
# 浏览器 F12 -> Application -> IndexedDB -> XianTu

# 导出存档备份（在游戏中）
游戏 -> 存档管理 -> 导出存档

# 清除缓存重新开始
浏览器 F12 -> Application -> Clear storage
```

## 性能优化建议

### 开发环境

1. **使用 SSD**: 提升 npm install 和构建速度
2. **增加 Node.js 内存**:
   ```bash
   set NODE_OPTIONS=--max_old_space_size=4096
   npm run serve
   ```

3. **禁用不必要的插件**: 提升 Webpack 构建速度

### 生产环境

1. **启用 Gzip 压缩**: Nginx/Apache 配置
2. **使用 CDN**: 加速静态资源加载
3. **启用浏览器缓存**: 合理设置 Cache-Control
4. **数据库索引优化**: 为常查字段添加索引
5. **API 响应缓存**: 静态数据使用 Redis 缓存

## 快速启动脚本（推荐）

### Windows PowerShell

**启动脚本** (`start-dev.ps1`):
```powershell
# 前端
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd '$PWD'; npm run serve"

# 后端
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd '$PWD'; .\.venv\Scripts\Activate.ps1; uvicorn server.main:app --reload --port 12345"

Write-Host "✅ 前端: http://localhost:8080"
Write-Host "✅ 后端: http://localhost:12345/docs"
```

**使用**：
```powershell
.\start-dev.ps1
```

### Linux/Mac

**启动脚本** (`start-dev.sh`):
```bash
#!/bin/bash

# 启动前端（后台）
npm run serve &

# 启动后端（后台）
source .venv/bin/activate
uvicorn server.main:app --reload --port 12345 &

echo "✅ 前端: http://localhost:8080"
echo "✅ 后端: http://localhost:12345/docs"
echo "按 Ctrl+C 停止所有服务"

wait
```

**使用**：
```bash
chmod +x start-dev.sh
./start-dev.sh
```
